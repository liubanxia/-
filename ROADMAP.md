# Project Phoenix Core Roadmap

## Current Status

Project Phoenix Core provides a reusable offline, DICOM-first medical imaging AI framework.

Implemented:

- DICOM folder and local image ingestion
- CT/DR routing architecture
- Lightweight model adapter interfaces
- Result normalization and lesion geometry handling
- Clinician-in-the-loop report drafting workflow
- Privacy-oriented case lifecycle management

## Near Term

- Expand synthetic CT/DR examples
- Improve documentation for new contributors
- Add more reproducible CPU-only examples
- Improve automated testing coverage
- Stabilize model adapter contracts

## Research Direction

- Lightweight medical AI deployment
- Knowledge distillation from large medical models
- Explainable multi-model fusion
- Offline-first clinical AI engineering patterns

## Scope Boundary

Project Phoenix Core is an engineering and research framework. It does not include vendor-specific hospital deployment, patient data, or clinical decision automation.
