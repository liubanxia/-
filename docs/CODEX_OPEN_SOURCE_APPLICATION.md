# Codex for Open Source Application Notes

## Project
Project Phoenix Core

## Summary
Project Phoenix Core is an open-source offline medical imaging AI framework for DICOM-based CT and DR research workflows.

The project focuses on modular engineering infrastructure rather than autonomous diagnosis. It provides interfaces for DICOM ingestion, modality routing, model adapters, result fusion, explainable outputs, and clinician-controlled reporting workflows.

## Why Open Source
Medical imaging AI engineering benefits from transparent interfaces, reproducible experiments, and community collaboration. Phoenix Core separates public software architecture from private clinical deployment environments.

## Public Scope
Included:
- DICOM workflow infrastructure
- Model adapter interfaces
- Research pipelines
- Synthetic examples
- Documentation
- Testing framework

Excluded:
- Patient data
- Hospital credentials
- Private deployment configuration
- Private model weights

## Technical Focus
- DICOM-first design
- CT/DR workflow support
- Offline-capable architecture
- Explainable result integration
- Human-in-the-loop review

## Project Status
The repository contains the public core foundation and documentation required for researchers and developers to explore medical imaging AI workflow engineering.
