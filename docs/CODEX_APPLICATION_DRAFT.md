# Codex for Open Source Application Draft

## Project

Project Phoenix Core

## Summary

Project Phoenix Core is an open-source offline medical imaging AI engineering framework focused on DICOM-first CT/DR research workflows, modular model adapters, result fusion, and clinician-reviewed reporting interfaces.

## Why this project exists

Medical imaging AI development often depends on cloud services, tightly coupled pipelines, or inaccessible deployment environments. Phoenix Core provides a reusable offline-oriented engineering foundation for researchers and developers working with DICOM-based imaging workflows.

## Open-source contribution

The repository provides:

- DICOM ingestion and spatial organization
- Modular model adapter interfaces
- CT and DR workflow foundations
- Result fusion and structured output interfaces
- Synthetic examples and documentation
- Testing and engineering utilities

## Safety boundary

This project is research and engineering software.

It does not include:

- Patient data
- Hospital credentials or private configurations
- Private model weights
- Clinical databases
- Production PACS integrations

It is not a medical device and does not replace clinician interpretation.

## Planned development

Future open-source work includes:

- More synthetic datasets and examples
- Additional model adapter interfaces
- Better documentation
- Expanded testing infrastructure
