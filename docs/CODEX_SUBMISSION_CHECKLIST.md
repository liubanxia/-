## Project description

Project Phoenix Core is an open-source offline medical imaging AI engineering framework focused on DICOM-first CT/DR research workflows, modular model adapters, result fusion, and clinician-reviewed reporting interfaces.

## Safety positioning

The project is research and engineering software. It is not a medical device, does not replace clinicians, and does not include patient data, private deployment settings, credentials, or proprietary model weights.
