# Contributing to Project Phoenix Core

Thank you for contributing.

## Scope

Project Phoenix Core focuses on open offline medical-imaging AI engineering: DICOM processing, model adapters, routing, result fusion and research workflows.

## Development principles

- Keep the core offline-first.
- Avoid committing patient data or private clinical information.
- Keep vendor-specific hospital integrations outside this public repository.
- Prefer modular adapters over hard-coded model dependencies.

## Pull requests

Please include:

- A clear description of the change.
- Tests or synthetic examples when applicable.
- Documentation updates for architecture changes.

## Data policy

Only synthetic or properly de-identified data may be used in this repository.
