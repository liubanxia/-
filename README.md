# Project Phoenix Core

Open-source core framework extracted from Project Phoenix for offline medical-imaging AI research and development.

> This public repository intentionally excludes hospital-specific integrations, patient data, private deployment configuration, credentials, model weights, logs, and local environment paths.

## Scope

- DICOM-first medical imaging workflows
- CT / DR pipeline architecture
- Model adapter interfaces
- Inference runtime and routing
- Result fusion
- Structured report-generation framework
- Offline and lightweight deployment oriented design

## Safety and privacy

This repository is intended for research and engineering. It does not include hospital-specific PACS/YUNPACS configuration, real patient data, or production credentials.

## Status

Public-core extraction is in progress from the private Project Phoenix development repository.
