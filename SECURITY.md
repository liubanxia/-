# Security and clinical-data policy

Do not submit real patient images, reports, identifiers, hospital credentials, private network details, access tokens, certificates, model weights, or vendor-specific deployment configuration to this public repository.

Use only synthetic or properly de-identified examples in issues, pull requests, tests, and documentation.

If sensitive clinical or credential material is accidentally committed, treat it as exposed: remove it from public history as appropriate, rotate affected credentials, and follow the relevant institutional privacy/security process.
